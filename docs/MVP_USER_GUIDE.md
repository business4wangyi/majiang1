# 🎮 AI辅助井字棋 MVP版本 - 用户指南

## 🌟 欢迎使用AI辅助井字棋！

这是一个智能的井字棋助手工具，可以帮助您学习井字棋策略、分析局面，并提供AI建议。无论您是初学者还是想要提高棋艺的玩家，这个工具都能为您提供有价值的帮助。

## 🚀 快速开始

### 启动程序
```bash
npm run ai-assistant:mvp
```

### 基本使用流程
1. 启动程序后，您会看到欢迎界面和使用说明
2. 输入 `play` 开始交互式下棋
3. 使用各种位置格式下棋（如：a1, 1,1, 或 5）
4. 观看AI分析每一步的建议
5. 使用 `demo` 查看预设局面分析
6. 输入 `quit` 退出程序

## 📖 详细功能说明

### 🎮 交互模式命令

#### 基础命令
- **`play`** - 开始交互式下棋模式
- **`demo`** - 查看演示和预设局面分析
- **`strategies`** - 查看可用的AI策略
- **`help`** - 显示帮助信息
- **`quit`** - 退出程序

#### 游戏中命令（在play模式下）
- **`reset`** - 重置棋盘，开始新游戏
- **`undo`** - 撤销上一步移动
- **`analyze`** - 分析当前局面
- **`board`** - 显示当前棋盘状态
- **`quit`** - 退出交互模式

### 📍 位置输入方式

我们支持三种直观的位置输入方式：

#### 1. 字母坐标格式
```
a1  b1  c1
a2  b2  c2  
a3  b3  c3
```
**示例**：`a1`（左上角）、`b2`（中心）、`c3`（右下角）

#### 2. 数字坐标格式
```
1,1  1,2  1,3
2,1  2,2  2,3
3,1  3,2  3,3
```
**示例**：`1,1`（左上角）、`2,2`（中心）、`3,3`（右下角）

#### 3. 数字位置格式
```
1  2  3
4  5  6
7  8  9
```
**示例**：`1`（左上角）、`5`（中心）、`9`（右下角）

### 🤖 AI分析功能

#### 多策略分析
程序集成了多种AI策略，每次分析都会显示：

1. **🧠 Minimax算法** - 理论最优策略，使用博弈树搜索
2. **🛡️ 防守策略** - 优先阻止对手获胜
3. **⚡ 贪心策略** - 追求局部最优解
4. **🎲 随机策略** - 随机选择合法位置

#### 分析结果包含
- **推荐位置**：AI建议的最佳落子位置
- **置信度**：AI对该建议的信心程度（0-100%）
- **决策理由**：详细解释为什么选择这个位置

#### 策略建议
- 实时的战术建议
- 基于当前局面的策略提示
- 帮助理解井字棋的基本原理

### 🎯 演示模式

#### 预设演示
输入 `demo` 后选择 `preset` 可以查看经典中局分析：
- 展示复杂局面的AI分析
- 多种策略的不同建议
- 详细的决策推理过程

#### 交互式演示
在演示模式中，您可以：
- 自由构建棋盘局面
- 选择放置X或O
- 实时查看AI分析
- 学习不同局面的最佳应对

## 💡 使用技巧

### 学习策略
1. **观察AI建议**：注意不同策略的推荐差异
2. **理解推理**：仔细阅读AI的决策理由
3. **实践应用**：在实际游戏中尝试应用学到的策略
4. **对比分析**：比较自己的想法和AI建议

### 提高棋艺
1. **基础原则**：
   - 见胜必取：发现获胜机会立即执行
   - 见败必防：阻止对手获胜威胁
   - 中心为王：优先占据中心位置
   - 角落次之：次优选择角落位置

2. **进阶技巧**：
   - 学会创造双重威胁
   - 理解对称性的重要性
   - 掌握开局和残局的关键点

### 常见问题解决

#### Q: 输入位置时提示无效怎么办？
A: 请检查：
- 位置格式是否正确（a1, 1,1, 或 1-9）
- 该位置是否已被占用
- 是否在正确的游戏模式下

#### Q: 如何查看所有可用命令？
A: 随时输入 `help` 查看完整的命令列表和说明

#### Q: AI分析结果看不懂怎么办？
A: 
- 仔细阅读"决策理由"部分
- 对比不同策略的建议差异
- 使用 `strategies` 命令了解各策略特点

#### Q: 如何重新开始游戏？
A: 在游戏中输入 `reset` 即可重置棋盘
