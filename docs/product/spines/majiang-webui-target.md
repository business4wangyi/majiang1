## 3. 硬不做

- 前端重写规则引擎或计分权威  
- 用功能/e2e 绿冒充视觉冲顶通过  
- 用「基本有」关闭毕业标准或冲顶行  
- 本脊骨一段内改 CLI 对局语义（另立切片）  
- Agent / `/loop` **自批**冲顶毕业  
- 一段未完成前偷开竞品整桌重绘（二段须人点名 + 新蓝图）
