## 3. 硬不做

- 前端重写规则引擎或计分权威  
- 用功能/e2e 绿冒充视觉冲顶通过  
- 用「基本有」关闭毕业标准或冲顶行  
- 本脊骨一段内改 CLI 对局语义（另立切片）  
- Agent / `/loop` **自批**冲顶毕业  
- 二段阶段A 未人批前用一段截图冒充竞品目标，或偷开整桌实现大改
