## 用户故事

作为玩家，我从已优化的大厅点进对局后，应看到一张可与商业麻将产品并排的自绘局内桌：强桌心、实体牌、印章动作条、绿毡金扣与大厅同气质——而不是 Web 面板桌。

## 终态效果（本波）

- 桌面 1440×900：阶段 A 自绘主帧人批 + 阶段 B 实现对照  
- 范围覆盖整桌沉浸 + 桌心/动作 + 手牌/牌河  
- 毕业线：与竞品局内截图并排可交付  
- 移动 390×844：只防回退抽检，不纳入本波视觉毕业  
- 大厅与 `core` 规则不动  

## 硬不做

- 不改 `#lobbyPage` / 大厅脊骨事实  
- 不改 `src/majiang/core/`  
- 不用 W8 旧图或竞品原图冒充自绘阶段 A  
- 无阶段 A 人批不得开大视觉实现或宣称视觉通过  
- Agent/`/loop` 不得自批毕业
