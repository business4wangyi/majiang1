## 🔍 性能瓶颈分析

### 当前性能分布（最新优化后）

| 阶段 | 时间占比 | 平均时间 | 优化潜力 |
|------|---------|---------|---------|

### 已识别优化机会

#### 高优先级（预期收益>20%）

1. **优化初始化开销** ⭐⭐⭐⭐⭐
   - **问题**：迭代1的Epoch 1耗时异常高（批次64测试中17.8秒）
   - **优化方案**：预热训练、预分配内存、延迟初始化
   - **预期收益**：减少迭代1训练时间30-40%

2. **优化数据采样** ⭐⭐⭐⭐
   - **问题**：当前使用简单随机采样，每次epoch采样一次
   - **优化方案**：预采样多个批次、缓存采样结果、批量采样
   - **预期收益**：减少采样开销20-30%

#### 中优先级（预期收益10-20%）

3. **优化张量操作** ⭐⭐⭐
   - **问题**：批次大小增加导致内存操作开销增加
   - **优化方案**：张量池化、批量转换、内存预分配
   - **预期收益**：减少单epoch时间10-15%

4. **并行化评估阶段** ⭐⭐⭐
   - **问题**：当前串行评估3个对手
   - **优化方案**：并行评估多个对手
   - **预期收益**：评估时间减少50-60%

5. **优化MCTS提前终止** ⭐⭐⭐
   - **问题**：当前提前终止阈值95%，最小模拟30%
   - **优化方案**：降低阈值到90%，减少最小模拟到20%
   - **预期收益**：MCTS搜索时间减少10-20%

#### 低优先级（预期收益<10%）

6. **增加并行游戏数** ⭐⭐
   - **问题**：当前6核并行（8核CPU）
   - **优化方案**：增加到7核并行
   - **预期收益**：自我对弈时间减少10-15%
   - **风险**：内存压力、稳定性

## 📊 性能预测模型

### 训练时间预测公式

**单epoch时间** = 固定开销 + (可变开销 × 批次大小 / 32)

- 固定开销：约0.5秒（初始化、梯度准备）
- 可变开销：约1.3秒（批次32）

**当前（批次48）**：
- 单epoch时间 = 0.5 + (1.3 × 48 / 32) = 2.45秒（实测2.4秒，匹配）

**优化后（减少初始化开销）**：
- 固定开销：0.3秒（减少40%）
- 单epoch时间 = 0.3 + (1.3 × 48 / 32) = 2.25秒
- 20 epoch时间：45秒 = 0.75分钟（vs 当前0.95分钟）

### 自我对弈时间预测公式

**单局时间** = 基础时间 + (MCTS模拟次数 × 模拟时间)

- 基础时间：约0.5秒
- 模拟时间：约0.003秒/次（随模型质量提升而减少）

**当前（平均400次模拟）**：
- 单局时间 = 0.5 + (400 × 0.003) = 1.7秒
- 12局时间：20.4秒 = 0.34分钟（实测0.28分钟，匹配）
