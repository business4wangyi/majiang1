# ⚫ Othello AI助手 - 快速开始指南

## 🚀 立即开始

### 1. 启动Othello CLI
```bash
npm run othello:cli
```

### 2. 基本命令
- `play` - 开始人机对战
- `demo` - 演示模式（推荐新手）
- `ai-battle` - 观看AI对战
- `rules` - 查看游戏规则
- `help` - 查看所有命令

## 🎮 游戏模式介绍

### 人机对战模式 (`play`)
与AI进行对战，获得实时分析和建议：
```
请输入命令: play
🎮 进入人机对战模式
```

**输入位置的三种方式：**
- 字母坐标：`d4`, `e5`
- 数字坐标：`4,4`, `5,5`
- 位置编号：`28`, `29`

### 演示模式 (`demo`) - 推荐新手
手动下棋并获得AI分析，适合学习：
```
请输入命令: demo
🎯 演示模式
```

### AI对战模式 (`ai-battle`)
观看不同策略的AI相互对战：
```
请输入命令: ai-battle
选择黑棋AI策略 (1-4): 3  # 启发式策略
选择白棋AI策略 (1-4): 4  # 极小极大策略
```

## 🤖 AI策略说明

1. **🎲 随机策略** - 随机选择，适合练习
2. **🍖 贪心策略** - 翻转最多棋子，短期收益
3. **🧠 启发式策略** - 平衡策略，推荐使用
4. **🎯 极小极大策略** - 最强AI，深度搜索

## 📋 游戏规则速览

### 基本规则
1. **黑棋先手**，白棋后手
2. **必须夹住对方棋子**才能下棋
3. **夹住的棋子全部翻转**
4. **无法下棋则跳过**
5. **双方都无法下棋时游戏结束**

### 策略提示
- **角落最稳定**（a1, a8, h1, h8）
- **避免给对手角落机会**
- **控制边缘有优势**
- **不要只看棋子数量**

## 🎯 学习路径

### 新手推荐
1. 先运行 `rules` 了解规则
2. 使用 `demo` 模式练习
3. 观看 `ai-battle` 学习策略
4. 尝试 `play` 模式对战

### 进阶用户
1. 尝试不同AI策略对战
2. 分析AI的决策理由
3. 学习位置价值评估
4. 研究开局和残局

## 🆘 常见问题

**Q: 如何知道哪些位置可以下棋？**
A: 在游戏中输入无效位置时，系统会显示所有合法位置。

**Q: AI分析的置信度是什么意思？**
A: 表示AI对这步棋的信心程度，越高表示AI认为这步棋越好。

**Q: 如何提高棋艺？**
A: 多使用演示模式，观察AI的分析和建议，理解每步棋的战略意图。

**Q: 游戏卡住了怎么办？**
A: 按 `Ctrl+C` 退出，或输入 `quit` 命令。
