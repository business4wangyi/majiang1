竞品图直接标注冻结页

基于真实对局图直接标注：区域结构、比例关系、主链路与交互约束（阶段A快捷方案）。

桌面基准（S-C）

A 桌心主舞台
B 左座位区
C 右座位区
D 底部手牌区
E 信息/日志侧区
F 目标牌与主链路提示
G 主动作区
A 目标占比 58%-64%，是第一视觉锚点。
D+G 必须近邻，避免“看底部点侧边”的跳视。
E 默认弱化，对比度低于 A/F 至少一个层级。
F 必须承载链路：谁打牌 -> 目标牌 -> 我可响应 -> 主动作。

移动基准（S-A）

M1 顶部局势摘要
M2 中部桌心+牌河
M3 手牌区（吸底）
M4 主动作区
M3+M4 形成单手闭环，点击热区 >= 44x44。
M2 显示目标牌与响应关系，不依赖 hover。
M4 默认单强主动作；ResponseWindow 默认“过”。
