# 状态映射附录（标注区 -> UI状态）

## 依据
- `docs/majiang/WEB_UI_PRODUCT_INTERACTION_DESIGN.md` 状态口径
- `annotated-reference/ANNOTATED_REFERENCE.html` 标注区
- `annotated-reference/ANNOTATED_SPEC.md` 冻结规格

## 标注区回顾
- 桌面：A/B/C/D/E/F/G
- 移动：M1/M2/M3/M4

## A. Lobby 三态映射

### 1) Idle
- 桌面：A(主视觉卡) + G(开始对局)
- 移动：M1(摘要) + M4(开始对局)
- 规则：仅一个强主动作 `开始对局`

### 2) Creating
- 桌面：A 显示创建进度，G 按钮锁定
- 移动：M1 显示 busy 文案，M4 锁定
- 规则：次级入口禁用

### 3) Error
- 桌面：A 显示错误原因，G 切换 `重试创建`
- 移动：M2 显示错误，M4 切换 `重试创建`
- 规则：保留上一配置

## B. Table 六态映射

### 1) WaitingAI
- 桌面：F 显示“等待AI动作”；G 仅保留等待态
- 移动：M2 显示等待原因；M4 不提供可提交动作
- 主动作：无强提交动作

### 2) PlayerTurn
- 桌面：D 可选牌；F 显示当前目标；G 强主动作 `出牌`
- 移动：M3 可选牌；M4 强主动作 `出牌`
- 主动作：`出牌`

### 3) ResponseWindow
- 桌面：F 显示“可响应原因”；G 默认强主动作 `过`
- 移动：M2 显示目标牌与响应原因；M4 默认 `过`
- 主动作：`过`（默认）

### 4) Submitting
- 桌面：G 按钮与 D 手牌锁定；F 显示提交中
- 移动：M3/M4 锁定；M2 显示提交中反馈
- 主动作：无（锁定态）

### 5) ActionError
- 桌面：F 显示错误；D 保留已选牌；G 提供 `重试` 主动作
- 移动：M2 显示错误原因；M4 `重试`
- 主动作：`重试`

### 6) Ended
- 桌面：F 显示结束结果摘要；G 仅 `查看结果`
- 移动：M2 显示结束摘要；M4 `查看结果`
- 主动作：`查看结果`

## C. ResultModal 四类型映射

### 1) tsumo
- 结构：类型 -> 关系(三家支付) -> 分差 -> 下一步
- 下一步主动作：`再来一局`

### 2) ron
- 结构：类型 -> 关系(点炮者) -> 分差 -> 下一步
- 下一步主动作：`再来一局`

### 3) draw
- 结构：类型 -> 流局原因 -> 分差 -> 下一步
- 下一步主动作：`再来一局` 或 `回大厅`

### 4) abort
- 结构：类型 -> 终止原因 -> 是否计分 -> 下一步
- 下一步主动作：`回大厅` 或 `重开`

## D. Replay/Diagnostics 映射
- 桌面：E 默认弱化；展开后显示 L1-L4 信息层
- 移动：诊断信息进入抽屉，不挤占 M3/M4
- 规则：不得抢 A/F（桌面）或 M2/M3/M4（移动）主链路

## E. 编码验收快检
1. 每态是否仅1个强主动作？
2. F/M2 是否完整表达“目标牌与可响应原因”？
3. D+G（桌面）/M3+M4（移动）是否始终邻接？
4. Submitting 是否真正锁定并有恢复路径？
5. ResultModal 是否四类型都闭环解释？
