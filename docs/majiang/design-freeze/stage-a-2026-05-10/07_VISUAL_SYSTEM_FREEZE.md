# 视觉系统冻结

## 牌面系统
- 正式态：资产化图案牌为默认主表达。
- 调试/降级态：文字牌仅在资产加载失败或诊断模式启用时可见。
- 明确禁止：在正常主路径中把文字牌作为默认展示。

## 色彩语义冻结
- 主行动：琥珀金（按钮、当前主链路提示）。
- 成功：绿色（提交成功、正向结果）。
- 可响应/警告：橙色（响应窗口、倒计时临界）。
- 错误：红色（ActionError、异常终止）。
- 诊断：蓝灰（弱化入口、展开层辅助信息）。

## 层级语义冻结
- L1：桌心主链路（第一眼必读）。
- L2：底部手牌 + 主操作。
- L3：其他三家状态与牌河历史。
- L4：侧栏事件流与诊断信息。

## 状态语义冻结
- 当前行动玩家：外圈描边 + 微光呼吸。
- 可响应：目标牌与可用动作同步高亮。
- 错误：内联错误条，保留可恢复入口。
- 成功：短促确认反馈后回归常态。

## 动效节奏分层
- 普通事件（摸牌、出牌、轮转）：120-220ms。
- 关键事件（可胡/结算出现）：220-360ms。
- 禁止超过450ms的阻塞动画。
