## 固定局势与信息模型

为避免设计发散，本轮目标图只画一个固定响应窗口态：

- 场景：东风局，牌山余量 36。
- 触发：右家刚打出目标牌。
- 我方：底部玩家，当前状态可胡。
- 主动作：`胡`，必须是唯一最强主按钮。
- 次动作：`过`，清晰可点但弱于主动作。
- 可选弱层级动作：`碰`、`杠` 可出现，但必须弱于 `胡`，不得与 `胡` 抢主动作。
- 禁止动作：不展示 `荣和`、`立直`、`听牌`、日文假名、罗马字或英文 UI 标签。
- 首眼链路：`右家弃牌 -> 目标牌高亮 -> 中心盘/提示确认来源 -> 底部主动作胡 -> 过`。

目标图里的文字只能辅助确认局势，不得承担主要解释。用户应先靠牌、位置、光效和动作层级看懂，而不是读大段说明。

## 新目标图必须重做的视觉架构

### 1. 实体牌系统

- 手牌、牌河、副露、目标牌都必须是实体牌，而不是 CSS 方块或网页按钮。
- 牌体需具备厚度、圆角边缘、侧面阴影、桌面投影和材质反差。
- 牌面图案密度必须接近商业麻将产品：图案为主语言，文字只作辅助。
- 最近打出的目标牌需比普通牌河更亮、更厚、更靠前，能成为响应链路的视觉起点。

### 2. 桌面透视

- 牌桌不再是平面矩形容器，而应形成微透视局内桌面。
- 自己手牌为最大、最清晰、最靠近镜头的底部层。
- 上家、对家、下家的牌河和手牌应按座位方向有旋转、缩放和透视差异。
- 桌面材质需有商业游戏桌感：深绿色竞技桌布、边缘包边、中心暗部与局部光照。

### 3. 中心计分/风位盘

- 桌心从空绿桌布重构为主舞台：中心盘 + 风位 + 局数/余牌 + 四家分数。
- 中心盘必须承载“谁打出什么牌、我可响应什么动作”的第一视觉链路。
- 当前行动方向需在中心盘或座位边缘同时表达，避免只靠文本说明。
- 中心盘应有明确的四向分数与风位读数，形式可参考 Riichi City 的中心电子盘，但不得逐像素复制竞品资产。
- 中心盘与右家目标牌之间必须建立视觉关系，例如短光束、方向脉冲、描边流向或中心盘对应边高亮。

### 4. 四家座位头像/状态

- 四家必须有头像或角色位，不再只是普通信息框。
- 每家座位需包含风位、分数、当前状态、最近动作和倒计时/高亮。
- 当前行动玩家需有持续可见的视觉强化，不能只靠标签墙。

### 5. 牌河空间

- 四家牌河围绕中心盘组织，方向、来源和时间顺序稳定可读。
- 牌河不能像普通列表或横排标签；必须像桌面上的弃牌区域。
- 响应目标牌需在对应来源牌河中被定位，并与动作层建立明确连线或光效关系。

### 6. 主动作层级

- 主动作区贴近自己手牌，本局势必须以 `胡` 为唯一最强动作。
- `胡` 可使用金色/高亮/更大按钮；`过` 为次动作，清晰但低强调。
- `碰`、`杠` 如出现，只能作为弱于 `胡` 的次级动作，不得形成多个并列主动作。
- 响应窗口必须让用户先读到目标牌，再理解“我方可胡”，最后读到主动作 `胡`。
- 同一状态只能有一个最强主动作，其他不属于当前局势的动作不得占位抢视觉。

## 画面硬约束

### 桌面 1440x900

- 底部手牌 + 主动作层占画面高度约 `24%~30%`，且手牌不得被信息条遮挡。
- 中心桌面主舞台占画面高度约 `55%~65%`，不能出现大面积无意义空绿桌布。
- 左右头像/状态区默认低于牌桌主舞台权重，不能变成 Web 侧栏。
- 目标牌必须位于右家牌河内，而不是漂浮在说明卡里。
- 右家座位、目标牌、中心盘、底部主动作之间必须形成一个可追踪的视觉路径。

### 移动 390x844

- 仍然先呈现游戏桌面，而不是纵向表单或信息卡堆叠。
- 底部手牌与 `胡/过` 操作必须同屏可见。
- 四家空间关系可简化，但不能退化成玩家列表。
- 解释文字最多一行短提示，不能把响应原因写成多段说明。

### 资产与风格边界

- 可以学习 Riichi City 的“商业游戏桌面架构”：实体牌、中心盘、四向牌河、头像座位、强动作按钮。
- 不得复制 Riichi City 的角色、图标、Logo、特定 UI 贴图或可识别美术资产。
- 本项目目标图应形成自有视觉表达，但第一眼必须与主参考同属商业麻将游戏局内截图。

## 给下一轮设计/生成工具的目标提示词

生成一张商业级中文广东麻将局内 UI 高保真目标图，唯一主参考为 Riichi City 的商业局内桌面架构，不继承日式立直术语，不混用其他产品风格。画布为 1440x900，横屏游戏界面，深绿色竞技麻将桌，微透视桌面，中心有发光的计分与风位盘，四家座位围绕桌面排列，每家有头像、风位、分数、状态和当前行动高亮。底部是我方实体手牌，象牙色麻将牌具有厚度、圆角、侧面阴影、桌面投影和清晰图案牌面；四家牌河围绕中心盘按方向排列，弃牌有真实桌面空间感。

固定局势：东风局，牌山余量 36。右家刚打出目标牌，目标牌必须出现在右家牌河中并被高亮。我方底部玩家当前可胡。目标牌通过右家牌河高亮、中心盘方向提示和底部响应层连接起来。底部手牌上方出现响应动作层，唯一最强主动作是“胡”，次动作是“过”；“碰”“杠”若出现只能弱于“胡”，不要展示“吃”作为强按钮。用户第一眼应能看懂“右家打出目标牌，我方可胡，当前应按胡或过”。

界面文字必须全部为简体中文广东麻将语境。必须使用“胡”，禁止出现“荣和”“立直”“听牌”；如需表达可胡状态，只能使用“可胡”或“叫胡”。不得出现日文假名、罗马字或英文 UI 标签。
