## 给编码 agent 的改稿单
> 本轮关闭 R2 实现验收；下列仅保留整桌冲顶残余，勿再以「微调冒充冲顶完成」。

- 保留：
  - 胶囊/印章动作层（`action-seal`）与 `胡` 唯一最强权重
  - 教学层关闭策略（beam/callout + `latest-action-wrap` 退出主舞台）
  - 角区稀疏与弱高亮局势语言
  - 筒条经典印花格位方向
- 修改：
  1. **作用范围**：牌面资产化（按需）  
     **具体改动**：若下一轮并排仍判定印花偏 CSS，再上 PNG/SVG sprite；保持现有格位语义。  
     **验收条件**：手牌/牌河近距观感接近目标图实体牌，而非「圆角矩形 + 色点」。  
     **禁止扩展**：不重做整桌布局；不引入日式术语。
  2. **作用范围**：底部次要 Web 态文案  
     **具体改动**：响应窗内弱化「等待操作」等通用 Web 提示，让主动作条自解释。  
     **验收条件**：并排时底部不再像表单工具栏副文案抢视线。  
     **禁止扩展**：不恢复桌心说明条/教学气泡。
  3. **作用范围**：右家牌河目标牌可读性  
     **具体改动**：强化牌河内目标牌抬升/光效（相对手牌同名弱匹配），保证首眼落在牌河而非只看动作条。  
     **验收条件**：无文案时 3 秒内仍先看到「右家那张三万」。  
     **禁止扩展**：不加回箭头/说明条。
- 验证：
  - 本文件结论回填 handoff；移动端帧补齐后再跑档位 B
  - 功能 acceptance 11/11 仅作基线，不替代本视觉结论
- 禁止：
  - 宣称「最顶级已通过 / 无条件竞品级」
  - 用 acceptance 或局部 CSS 微调冒充整桌冲顶完成
  - 退回圆钮 HUD 或深色 Web 工具条
