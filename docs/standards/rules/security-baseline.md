# 安全红线（本仓）

> **R1** — 涉及密钥、敏感操作、网络鉴权时 **MUST Read**。

## 1. 敏感信息

- **禁止硬编码**：Token、私钥、账号密码、API Key、云凭证不得写入源码或提交到 Git
- **配置外置**：用环境变量、本地未跟踪配置或密钥注入渠道
- **日志脱敏**：日志/错误信息不得输出完整密钥或隐私字段

## 2. Web / XSS

- 用户输入与外部内容进入 HTML/模板前须转义或白名单处理
- 禁止默认使用 `eval`、动态拼任意 JS 执行不可信字符串
- Web UI 诊断接口仅用于本地/受控环境；不得暴露可远程改核心规则的入口

## 3. 游戏核心边界

- UI / 适配层不得为「好看」绕过 `src/*/core/` 判定而伪造合法动作结果
- 训练脚本与云端 workflow 不得把密钥写进仓库内 YAML；用 GitHub Secrets / 环境注入

## 4. AI 执行

- 发现硬编码密钥：阻止提交并提示外置
- 破坏性安全相关操作须用户确认
