# 麻将游戏 - Majiang

一个基于命令行的广东麻将游戏。

## 游戏特点

- 基于命令行界面
- 支持AI玩家
- 支持广东麻将规则
- 完整的吃碰杠胡等操作

## 使用方法

```bash
npm install
npm start
```

在测试模式下运行：

```bash
npm start -- --test
```

## 调试模式说明

为了帮助分析和修复游戏中的问题，我们添加了调试模式功能：

### 调试参数

1. `--debug`: 启用调试模式，输出详细的调试日志
2. `--step`: 启用单步执行模式，限制执行步数便于追踪问题

### 使用方法

```bash
# 启用调试模式
node dist/index.js --debug

# 启用调试和单步执行模式
node dist/index.js --debug --step

# 设置更高的步数限制（通过修改源代码中的MAX_DEBUG_STEPS常量）
```

### 调试输出格式

调试日志以 `[DEBUG]:` 开头，以区别于正常游戏输出。游戏内部组件的日志会有额外前缀，例如：

- `[game.currentPlayerDiscard]`: 来自游戏核心中的出牌方法
- `AI出牌处理开始/结束`: 标记AI出牌处理流程的边界

### 解决卡住问题

如果游戏卡在某个状态，使用调试模式可以帮助识别：

1. 当前游戏状态
2. 各玩家的状态和手牌情况
3. 哪些方法被调用及其参数和返回值
4. 错误发生的确切位置和原因

调试日志会详细跟踪游戏循环中的状态变化，非常有助于定位问题。

## 开发环境

- Node.js (14.x以上)
- TypeScript

## 如何运行

1. 安装依赖：
   ```
   npm install
   ```

2. 编译TypeScript：
   ```
   npx tsc
   ```

3. 运行游戏：
   ```
   node dist/index.js
   ```
